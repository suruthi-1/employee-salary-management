# Employee Salary Management System

A Python Tkinter application for calculating and displaying employee salary details.

## Features

- Employee ID
- Employee Name
- Department
- Basic Salary
- Bonus Calculation
- Deduction Calculation
- Net Salary Calculation
- Dashboard Page
- Result Page
- Reset / New Employee option

## Salary Calculation

- Bonus = 10% of Basic Salary
- Deduction = 5% of Basic Salary
- Net Salary = Basic Salary + Bonus - Deduction

## Technologies Used

- Python 3.14
- Tkinter

## How to Run

Run the following command:

```bash
python employee_salary_management.py.
